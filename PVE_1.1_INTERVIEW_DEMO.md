# PVE 1.1 Interview Demo

## Positioning
PVE 1.1 supports all-category packaging project intake and validation readiness. It does not replace category engineering.

## Demo flow
1. Create a project and select category, objective, and change type.
2. Show category-specific input and document guidance.
3. Generate and upload the Excel template.
4. Show validation errors, source classification, readiness, blockers, and unavailable-output reasons.
5. Show commercial opportunity, testing checklist, and executive report.

## Cases
- Commercially attractive and ready for testing.
- Attractive but blocked by missing technical evidence.
- Insufficient data because critical mandatory inputs are absent.

## Message
The platform improves intake quality, exposes missing evidence, and creates a traceable handoff for engineering and human approval. Readiness is not approval.

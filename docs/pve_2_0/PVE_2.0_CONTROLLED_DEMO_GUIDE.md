# PVE 2.0 — Controlled Demonstration Guide

## Demonstration objective

Show the governed path from two synthetic Word specifications to a source-traceable, human-confirmed canonical dataset draft without claiming technical approval or live-model performance.

## Sequence

1. State the frozen baseline: `1f6f6ade9bb1370d8aace750b8e0e1cf63441dbe`.
2. Explain that Build Groups A–F remain in draft PR #54.
3. Present one existing and one proposed synthetic DOCX specification.
4. Show deterministic paragraph, heading, table and cell extraction.
5. Show stable source-block IDs and document hashes.
6. Explain the provider-neutral extraction contract and 25-field allowlist.
7. Show confidence, ambiguity and source-grounding checks.
8. Show human confirmation or correction while retaining the original value.
9. Show deterministic existing-versus-proposed comparison.
10. Show confirmed-only canonical draft mapping.
11. Show canonical validation issues, including incomplete-data blockers.
12. Show immutable snapshot hashing and append-only persistence.
13. Present the synthetic evaluation report and its claim boundary.

## Mandatory wording

> This demonstration proves governed document intake, traceability, human review, deterministic comparison and immutable evidence handling. It does not prove production-model accuracy, engineering qualification, autonomous approval or realized savings.

## Stop conditions

Do not continue the demonstration if:

- source evidence is missing;
- document role is unresolved;
- candidate ambiguity is unresolved;
- a field remains unconfirmed;
- canonical validation reports blockers;
- document content is scanned or image-only;
- confidential real-company data is proposed for use.

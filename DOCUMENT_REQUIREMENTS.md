# PVE 1.1 Document Requirements

## Structured register only

PVE 1.1 records document metadata and filenames. It does not extract, OCR, interpret, or validate unstructured document contents.

## Mandatory documents

- Current specification
- Proposed specification
- Supplier quotation

These establish the baseline, proposed state, and commercial basis. Missing current or proposed specifications blocks readiness progression.

## Recommended documents

- Drawing
- Laboratory report
- Trial report
- Regulatory certificate

A recommended document becomes effectively blocking where the selected category, objective, or change type requires evidence for safety, compliance, barrier, compression, leakage, migration, compatibility, seam, pressure, or line-performance assessment.

## Optional documents

- Sustainability certificate
- Damage history

Additional project-specific records may later include purchase orders, cost breakdowns, transport trials, pallet patterns, supplier declarations, quality standards, and reviewer notes.

## Required register fields

Document ID, document type, document name, category, baseline/proposed designation, supplier, date, valid-until date, filename/reference, verification status, requirement level, uploaded/missing status, and reviewer comments.

## Evidence rules

- Uploaded filename is not evidence that content was verified.
- Supplier declaration is not laboratory evidence.
- Expired certificates are blockers when validity is mandatory.
- Proposed test evidence must match the proposed specification.
- Historical decision snapshots and dataset versions remain immutable.
